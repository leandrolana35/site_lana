Como usar o editor

  • Clique em "Ativar Edição" para entrar no modo de edição
  • Passe o mouse sobre qualquer texto para vê-lo destacado — clique para editar
  • Passe o mouse sobre uma imagem para ver o botão "Trocar imagem" — clique e cole a URL
  • Passe o mouse sobre um link/botão — aparece um badge azul "Editar URL" no topo
  • Clique fora do texto para confirmar a edição
  • Quando terminar, clique em "Baixar index.html" para salvar o arquivo

Para imagens: faça upload no WordPress (Mídia → Adicionar Nova), copie o link e cole aqui.
